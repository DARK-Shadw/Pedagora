══ RULE 1: ALL MATH MUST USE katex.render() — MANDATORY ══

NEVER use textContent, innerHTML, or SVG <text> for math. Those produce ugly raw text like "\frac{a}{b}" instead of rendered equations.

CORRECT — create a div, render LaTeX into it, then animate:
  const eqEl = document.createElement('div');
  eqEl.style.cssText = 'position:absolute; left:50%; top:40%; transform:translate(-50%,-50%); font-size:2em; opacity:0;';
  document.getElementById('canvas-container').appendChild(eqEl);
  katex.render('E[X] = \\sum_{i} x_i \\cdot P(x_i)', eqEl, {throwOnError: false, displayMode: true});
  tl.to(eqEl, {opacity: 1, duration: 0.6}, 'show-equation');

For colored math terms, render into separate elements:
  const termEl = document.createElement('span');
  termEl.style.cssText = 'position:absolute; top:50%; left:25%; opacity:0; font-size:1.6em;';
  document.getElementById('canvas-container').appendChild(termEl);
  katex.render('P(A|B)', termEl, {throwOnError: false});

WRONG — these all produce broken unrendered text:
  el.textContent = 'P(X=x)';
  el.innerHTML = '\\frac{a}{b}';
  svgText.textContent = '\\Omega';
  d3.select('text').text('\\sum x');

══ RULE 2: EVERY STEP LABEL MUST HAVE ANIMATION — MANDATORY ══

Each tl.addLabel() MUST be followed by tl.to(), tl.from(), or tl.fromTo() calls. A label with no animation after it = a dead step where nothing changes visually.

CORRECT — visible change at each step:
  tl.addLabel('show-title');
  tl.from(titleEl, {opacity: 0, y: -30, duration: 0.5});

  tl.addLabel('show-equation', '+=0.3');
  tl.from(eqDiv, {opacity: 0, scale: 0.85, duration: 0.6});
  tl.to(eqDiv, {y: -20, duration: 0.3}, '>');

  tl.addLabel('highlight', '+=0.5');
  tl.to(highlightBox, {opacity: 1, duration: 0.3});
  tl.to(term1, {color: '#3B82F6', scale: 1.15, duration: 0.4}, '<');

WRONG — labels exist but nothing animates:
  tl.addLabel('step-1');
  tl.addLabel('step-2');  // NOTHING happened at step-1!
